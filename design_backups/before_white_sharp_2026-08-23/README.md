# Tasarım Geri Dönüş Noktası

Bu klasör, beyaz zeminli ve keskin köşeli tasarım dönüşümünden hemen önceki
`lib/` kaynaklarını içerir.

Kullanıcı “eski haline geri dön” dediğinde yalnızca bu tasarım yedeğindeki
`lib/` dosyaları güncel projeye geri uygulanmalıdır. Sonraki veri veya özellik
değişiklikleri ayrıca değerlendirilmeden üzerine yazılmamalıdır.
