# Doğadayım UI Kataloğu

Bu klasör yalnızca geliştirme içindir; yayınlanan mobil uygulamanın açılışına,
haritasına veya veri akışına dahil değildir.

Kataloğu Chrome'da açmak için proje kökünde şunu çalıştırın:

```bash
flutter run -d chrome -t widgetbook/main.dart
```

Buradan açık/koyu temada temel butonları, yükleme iskeletini ve boş/hata
durumlarını ayrı ayrı kontrol edebilirsiniz. Yeni ortak arayüz bileşeni
eklendiğinde, ilgili farklı durumunu `main.dart` içindeki kataloğa ekleyin.
